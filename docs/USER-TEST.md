No user interviews or usability results have been collected yet. Use this sheet to record real observations.

## Tasks (do not coach the participant)
1. Add a fictional car with manual MPG. What do you think “History needed” means?
2. Record a tire-pressure check. Find the new due date and its source.
3. Set a wash interval, then record a wash. Explain what changed.
4. Load the sample car, request the dirt-road example, apply one suggestion and dismiss another. Explain whether AI was used.
5. Compare the gas-detour example. Add $20/hour as the value of time. Explain why the verdict changed.
6. Export a backup. Refresh and confirm the history is still there.
